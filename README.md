# WA Name List

Add names one by one and share the finished list on WhatsApp. No cutting and pasting between chats.

Repo: https://github.com/circleone69/wa-name-list

Live app (after Pages is on): https://circleone69.github.io/wa-name-list/

## Turn on GitHub Pages (one-time)

The app files are already in this repo. Pages is not live yet until you flip one setting:

1. Open https://github.com/circleone69/wa-name-list/settings/pages
2. Under **Build and deployment** → **Source**, choose **GitHub Actions**
3. Open https://github.com/circleone69/wa-name-list/actions
4. Click **Deploy GitHub Pages** → **Run workflow** → **Run workflow**
5. Wait about a minute, then open https://circleone69.github.io/wa-name-list/

If that URL still says "There isn't a GitHub Pages site here", wait another minute and refresh. First deploy can lag.

## Use the app

1. Open the Pages URL on your phone.
2. Type a name and tap **Add**.
3. Keep adding names as they come in.
4. Tap **Share on WhatsApp** when you want the numbered list in a chat.
5. Optional: browser menu → **Add to Home Screen**.

Names stay in that phone's browser. They are not uploaded to GitHub.
