# WA Name List

Add names one by one and share the finished list on WhatsApp. No cutting and pasting between chats.

Live app: https://circleone69.github.io/wa-name-list/

Repo: https://github.com/circleone69/wa-name-list

## Use the app

1. Open the live link on your phone.
2. Type a name and tap **Add**.
3. Keep adding names as they come in.
4. Tap **Share on WhatsApp** when you want the numbered list in a chat.
5. Optional: browser menu → **Add to Home Screen**.

Names stay in that phone's browser. They are not uploaded to GitHub.
