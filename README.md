# WA Name List

Add names one by one and share the finished list on WhatsApp. No cutting and pasting between chats.

## Use it

1. Open `index.html` on your phone, or enable GitHub Pages on this repo and open the Pages URL.
2. Type a name and tap **Add**.
3. Keep adding names as they come in.
4. Tap **Share on WhatsApp** when you want the numbered list in a chat.

Names are stored in the browser on that phone. They are not uploaded anywhere.

## Put it on your home screen

In Safari or Chrome: Share / menu → Add to Home Screen.
